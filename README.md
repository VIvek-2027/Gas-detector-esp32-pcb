# Gas-detector-esp32-pcb
ESP32-based LPG, PNG/Methane and CO gas detector with buzzer and led warning status PCB industry ready.

## Overview

An ESP32-based gas detection PCB designed using Altium Designer.

The project includes schematic design, PCB layout, BOM and manufacturing Gerber files.

## Main Features

- ESP32-based controller
- LPG gas detection
- PNG/Methane gas detection
- CO gas detection
- USB-C power input
- Power protection circuitry
- Programming/debug interface
- PCB manufacturing files

## Design Software

- Altium Designer
- Schematic Capture
- PCB Layout
- Design Rule Checking
- Gerber Generation
